# הדגמה: הזמנת תור אוטונומית (אב טיפוס)

Node 24, בלי תלויות ובלי build.

## הרצה
```
node server.js        # http://localhost:3000   (רופא/ה: http://localhost:3000/doctor)
node test.js          # בדיקות (מרים שרת זמני על פורט פנוי, בלי מפתח)
```

## מודל שפה (לא חובה)
העתיקו `.env.example` ל-`.env` ומלאו `LLM_MODEL` (המזהה המדויק מהספק, למשל מודל Qwen חינמי) ו-`LLM_API_KEY`.
`LLM_BASE_URL` ברירת מחדל: OpenRouter. בלי מפתח, או אם הקריאה נכשלת, המערכת עוברת בשקט למסווג מילות מפתח מקומי (נקודה אפורה בפינה; ירוקה = מודל חי).
המודל משמש רק לסיווג טקסט חופשי, למיפוי תשובה מוקלדת לאפשרות, ולניסוח הסיכום. ההכוונה נקבעת רק ב-`rules.js`.

## איך מדגימים
1. פותחים את `/` (בטלפון) ואת `/doctor` בחלון נוסף. לוחצים על אייקון המבחנה בפינה העליונה השמאלית: "תרחישי הדגמה". כל תרחיש משתמש בפרופיל נועה לוי (34).
   - כאב בטן מאתמול: ענו "לא" לכל השאלות. מרפאה בלבד, תוך 48 שעות.
   - חידוש מרשם: בקשה דיגיטלית, שגרתי.
   - כאב בחזה: "כן" בשאלה הראשונה, מסך עצירה אדום, לא בר הזמנה.
   - פריחה מגרדת: וידאו מומלץ + שלב צירוף תמונה (מדומה), טלפון נעול.
2. בוחרים מועד ומאשרים: התור מופיע אצל הרופא/ה בתוך 1.5 שניות, עם הדגשה. מרחיבים שורה לסיכום לפני ביקור.
3. המתג "לפי שעת הזמנה / לפי דחיפות" מראה לפני ואחרי.
4. מחליפים מבוטח/ת דרך הכותרת (71 עם סוכרת, 28 בהריון) כדי לראות העלאת דחיפות. "איפוס" בתפריט מנקה הכול.

כל הנתונים בדויים. כל התורים נקבעים אצל ד"ר רונית שפירא (רופאת משפחה בדויה).
